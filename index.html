An FAQ accordion is an interactive user interface component that allows users to expand and collapse answers by clicking on questions.

FAQ accordions save space and organize information clearly. Users can open only the questions they are interested in.

This project uses HTML5 for structure, CSS3 for styling and JavaScript for interactive behavior.

JavaScript detects button clicks and uses DOM manipulation and classList methods to open or close the selected answer.
